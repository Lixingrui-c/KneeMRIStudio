# 分割和配准表面显示版

以本次提交的主窗口和 vtk_loader 为基础，保留四视图、组织选择和不透明度弹窗，整理任务接口与显示层。交付文件未覆盖原项目。

## 替换与启动

先备份 client 原文件，再把本目录的 app.py、vtk_loader.py、AnalysisWorker.py 放入 UI-project/client。api_client.py 和 modify_dialog.py 是读取到的现有配套版本，附在本目录供独立运行；如果自己的版本有新增内容，请保留并核对接口，不要盲目覆盖。

客户端环境需要 PyQt5、vtk、numpy、nibabel、scipy、requests。新增 nibabel/scipy 用于读取完整 affine，以及必要时将标签以最近邻重采样到原始 MRI 参考网格。

从项目根目录启动：

```powershell
python -m client.app
```

也支持在 client 目录执行 python app.py。默认服务器 http://127.0.0.1:8000，可通过 KNEE_SERVER_URL 环境变量指定。

## 使用顺序

1. 打开原始 MRI，明确选择左右膝（不推测）。
2. 点击“分割 / 显示设置”，选择组织和不透明度，点击“分割并显示”。
3. 上传、启动分割、查询、下载均由 AnalysisWorker 执行；结束后显示受试者组织表面。
4. 点击“配准并显示”，继续使用相同 case_id。当前版本根据已知模板配置仅允许右膝配准。
5. 配准成功后读取 files/registration，即 warped_template_seg.nii.gz，生成青色线框，与受试者彩色实面叠加。
6. 用顶部开关切换两组模型，模板滑块控制模板透明度；组织选择控制两组对应组织。点击“配准质控”查看下载的 QC JSON。

显示网格由标签 1～5 的二值掩膜以等值面 0.5 提取，无额外几何平滑，使用 NIfTI affine 放到统一世界坐标。空标签跳过，不导致其他模型丢失。模型缓存后，调透明度不重新生成模型、不重置相机。

这里展示的是“配准后标签图生成的显示网格”，不是后端形态学指标实际使用的 scb/iC/oC 分析网格。模板与患者的差异不能当作红绿缺损图。

三张切片保留原始 MRI 中心切片显示；按键名 x/y/z 对应，避免旧代码 Z/X/Y 返回顺序混淆。影像先做 closest-canonical 轴重排，斜采集仍为图像网格平面，不宣称已重建严格解剖 MPR。本版不新增模板 MRI 切片叠加，也不请求尚未添加的 registration_image 接口。

## 任务行为

- 停止等待仅停止客户端跟踪，不取消服务器任务；网络请求会在返回或超时后退出。
- “继续等待 / 重取结果”复用 task_id，不重复启动算法。
- 仅在确认服务器任务失败后使用“重新提交任务”；未知网络状态应先继续查询。服务器仍会拒绝同病例重复活动任务。
- 运行期间禁用切换文件；停止等待后切换病例需确认。关闭窗口时先请求线程退出，再安全关闭 VTK，避免阻塞主线程调用 wait()。
- 当前客户端未跨应用重启保存病例/任务状态；现有服务器也只保存内存任务状态。服务器重启后需重新创建病例。
- 本版未接入体积/厚度结果表格，保留禁用入口，聚焦此次要求的分割及配准表面显示。
